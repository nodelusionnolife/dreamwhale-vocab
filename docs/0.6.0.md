2026-10-20。

## 题库

在「今日」「词库」「专项」选择四级、六级或混合，再选择全部或高频。选择自动保存，也用于聊天抽题。暂存组继续原范围，下一组采用新选择；旧存档默认全部，原题号、收藏、错题和历史成绩保留。

四级补入大纲主词的 4,126 个拼法，新增词义辨认和听音拼写 8,252 题。六级新增 213 道重点题：64 个交叉命中词各有两道填空和一道选择，另有搭配、短语、词形、易混、改错、阅读、表达各三题。

高频采用同级别两个渠道共同收录的标准。四级比较南京大学 A / B 级词汇与新东方在线 2014 年十篇资料；六级比较云南农业大学公开 1500 词资料与新东方在线 2019 年 List 1–56。系列页面和重复词不增加票数。它们是历史备考资料，不是官方考频排名；级别仍以中国教育考试网大纲标记为准。词形、页码、来源链接与哈希详见 [来源说明](../content-sources/README.md)。

派生词栏未逐项展开，应用词数包括原有扩展练习。词义、听写覆盖所收主词，语境和专项覆盖其中一部分。释义使用 MIT 许可的 ECDICT 并校订部分常用义，没有逐词完成独立词典审校。

## 平台与构建

安卓、Windows 和网页共用源码。两端各自保存，通过备份文件迁移；客观题本地判分，聊天与情境表达使用用户配置的模型。学习朗读使用系统声音，在线 TTS 只用于梦鲸交流。安装、备份和构建环境见 [应用说明](../APP.md)。

```text
npm ci
npm test
npm run build:single
npm run android:build
npm run desktop:build
node tools/export-wordbanks.mjs dist/releases/0.6.0
```

Android 构建输出为 `android/app/build/outputs/apk/debug/app-debug.apk`；Windows 输出在 `src-tauri/target/release/bundle/nsis/`。测试签名文件不随源码提供，换机器构建的 APK 不保证能直接覆盖已安装版本；正式发行需自行管理签名。题库导出属于内容数据，不能通过「导入学习记录」导入。

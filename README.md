# 梦鲸词汇 · 每天一点点

梦鲸词汇是一款支持网页、Android 和 Windows 的英语学习工具。你可以按计划记单词、复习错题、练习听写，也可以和梦鲸聊天，把学到的词用进表达里。

客观题在本地判分，无需模型账号；聊天和情境表达由你配置的语言模型提供服务。学习记录保存在当前设备，支持手动导入导出。

![梦鲸词汇的词库与高频筛选](docs/images/library.png)

## 主要功能

| 入口 | 可以做什么 |
|---|---|
| 今日 | 设置每日目标，分开学习新词和到期复习，暂存并继续练习 |
| 词库 | 选择四级、六级或混合，以及全部或高频；搜索、收藏和整理错题 |
| 专项 | 按主题和难度练习词义、填空、搭配、词形、易混词、听写等 11 种题型 |
| 梦鲸 | 自由交流、口语练习和考试复盘；聊天题卡与日常练习共用学习记录 |
| 设置 | 管理档案、模型、语音、外观和备份 |

学习采用间隔复习：区分独立答对、提示后答对、看过讲解和跳过，并据此安排下一次练习。错题保留当时的题目、答案和讲解，可单题重练或成组巩固。

界面适配手机和电脑，提供深浅色、大字、减少动效，以及随时间变化的海边书房场景。

## 开始使用

### 网页版

安装 Node.js 后，在项目目录运行：

```bash
node serve.mjs
```

打开 `http://127.0.0.1:5173/` 即可学习，日常客观题不需要填写 API Key。

仓库也提供 [单文件网页版](dist/dreamwhale-vocab.html)，代码和图片均已内联。可用本地 HTTP 服务打开；浏览器需要允许本地存储。直接双击文件的 `file://` 运行方式尚未实测。

### Android 与 Windows

两个应用共用网页版的题库与学习规则。仓库包含完整构建工程，安装包需按下方命令生成。

- **Windows x64**：新安装默认目录为 `%LOCALAPPDATA%\Programs\Dreamwhale`。显示名称仍为「梦鲸词汇」，安装时可以更改目录；已有安装升级时沿用原目录。
- **Android**：最低 Android 7.0，需要较新的系统 WebView。项目生成的 APK 使用本机构建环境的测试签名。

安装环境、朗读设置与迁移方法见 [应用说明](APP.md)。

## 词库与题目

内置 **12,387 道题、5,636 个词与表达、11 种题型**。题库和高频范围会同时用于今日学习、词库、专项与聊天出题；切换范围保留学习记录和暂存组。

| 题库 | 全部词与表达 | 全部题目 | 高频词与表达 | 高频题目 |
|---|---:|---:|---:|---:|
| 四级 | 4,378 | 9,472 | 290 | 662 |
| 六级 | 1,262 | 2,915 | 188 | 616 |
| 混合 | 5,636 | 12,387 | 477 | 1,278 |

级别依据[中国教育考试网官方大纲](https://cet.neea.edu.cn/xhtml1/folder/16113/1588-1.htm)的主词标记，并保留项目扩展练习。派生词栏未逐项展开，英美拼法和同形词的整理口径见来源说明。

高频采用同级别两个渠道共同收录的标准：四级比较南京大学公开词表与新东方在线资料，六级比较云南农业大学公开资料与新东方在线资料。同站系列和重复词不增加票数；这是历史备考词表的交集，不是官方真题考频排名。

词义与听写覆盖所收大纲主词，语境及专项覆盖其中一部分。中文释义整理自 ECDICT 并校订部分常用义，题目为项目自编；没有逐词完成独立词典审校。

每个大纲词保留来源页码，高频词可查看命中渠道。完整来源、许可和数据再生成方法见 [词库来源](content-sources/README.md)。

## 模型与朗读

在「设置 → 模型」填写你自己的模型接口与 Key。支持 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages 和 Gemini 协议，提供常见服务商以及 Ollama、LM Studio 的连接预设。模型名可按账号权限修改。

客观题由本地规则判分；情境表达调用模型评价。网络失败或模型无法判断时，不会直接记为答错。网页版直连模型端点，需要服务端允许浏览器跨域访问。

- **学习朗读**：单词、例句、题干、答案与听写使用系统声音，支持英美音和 0.50–1.50 倍语速。离线能力取决于设备已安装的英语语音。
- **梦鲸语音**：可使用系统声音，或单独配置阿里百炼、MiniMax。支持段落、整条消息和回复完成后自动朗读，在线 TTS 仅用于梦鲸交流。

在线模型和语音服务使用各自的 Key，费用由所选服务商收取。具体配置见 [应用说明](APP.md)。

## 数据与备份

两个设备各自保存进度，通过「设置 → 数据」导出和导入 JSON 备份，暂不提供自动云同步。

学习历史与收藏可以合并，重复导入不会重复计分；聊天冲突会另存副本。备份不包含 API Key、未发送草稿或正在进行的练习组，换设备后需要重新填写 Key。

网页版使用浏览器本地存储，Windows 和 Android 应用使用各自的加密存档。卸载或清除应用数据前，请先导出备份。

## 开发与构建

网页源文件可直接用 `node serve.mjs` 预览。构建原生应用需要 Node.js 22+ 和锁文件中的依赖：

```bash
npm ci
npm test
npm run dev:app
```

| 命令 | 输出或用途 |
|---|---|
| `npm run build:single` | 生成 `dist/dreamwhale-vocab.html` |
| `npm run build:app` | 生成原生应用使用的网页资源 `app-dist/` |
| `npm run android:build` | 生成 Android 测试 APK |
| `npm run desktop:build` | 生成 Windows x64 安装程序 |
| `node tools/export-wordbanks.mjs dist/wordbanks` | 导出词表 CSV、来源对照和题库 JSON |

Android 构建需要 JDK 21 和 Android SDK；Windows 构建需要 Rust MSVC、Visual Studio C++ Build Tools、Windows SDK 和 WebView2。详细环境变量和输出路径见 [构建说明](APP.md#开发与构建)。题库 JSON 是内容数据，不能通过学习记录导入。

```text
src/content/       词库、题目、角色与素材清单
src/engine/        判分、选题、复习规则与提示词
src/app/           学习与聊天流程
src/ui/            页面和交互
src/gateway/       模型协议与流式响应
src/storage/       学习、聊天、配置与备份
src/platform/      浏览器和原生系统适配
android/           Android 工程
src-tauri/         Windows 工程与安装器
content-sources/   词库来源、比对数据与许可
tests/            自动检查
tools/            构建、内容生成与导出工具
```

自动检查覆盖判分、存档、备份合并、筛选和构建。设备语音效果、真实模型兼容性，以及 Android 真机和 Windows 覆盖升级仍需在目标设备验证。

# 梦鲸词汇 · 鲸鱼娘英语对话副本

一个在浏览器里直接打开的独立小站：和「鲸鱼娘」自由对话，她按节奏给你出四级词汇题。
零依赖、无后端、无构建步骤也能跑；API Key 由使用者自己填（BYOK），不经过任何第三方服务。

## 跑起来

```bash
node serve.mjs          # 默认 5173 端口，打开 http://127.0.0.1:5173/
```

也可以直接打开 `dist/dreamwhale-vocab.html`——那是打包好的单文件版本，代码、背景、11 张表情全部内联在里面。

> 说明：**表情图走远程图床**。
>
> 「直接双击（`file://`）打开」预期可用（脚本已全部内联成普通脚本，没有任何模块请求），
> 但这条**只验证过 http 方式**，未在 `file://` 下实测过。

首次打开会让你填「她怎么称呼你」和性别；然后在「设置」里填模型端点、模型名、API Key。

## 两种用法

| 形式 | 入口 | 特点 |
|---|---|---|
| 多文件（开发用） | `index.html` | 词库按需加载，聊天模式首屏约 217 KB；改源码刷新即生效 |
| 单文件（分发用） | `dist/dreamwhale-vocab.html` | 约 875 KB，双击即开；改源码后要重新打包 |

```bash
npm test                # 跑自测（311 项，零依赖）
npm run build:single    # 重新打包单文件 → dist/dreamwhale-vocab.html
```

## 它是怎么工作的

**词源和对错都由代码决定，不由模型自由发挥。** 每 N 条角色回复，代码从内置四级词库里抽一道题，
把题目用 `<Question>` 包起来注入这一轮的用户消息；答案以 `<AnswerKey>` 附在私有的参考区，
要求模型核对但不得念出。对错判定发生在对话里（提示词层的四条作答分支）。

```
src/content/   内容层：人设、提示词、文风规则、表情表、词汇表、题库、梗表
src/engine/    引擎层：出题节奏、会话状态、标记解析、限额与裁剪、资产解析（纯逻辑，不碰浏览器 API）
src/gateway/   网关层：OpenAI 兼容调用、用量与缓存字段归一化、地址归一化
src/storage/   存储层：唯一接触 localStorage 的模块，数据按 key 拆分存放
src/platform/  平台层：本地媒体地址解析（多文件版给相对路径，单文件版查内联映射表）
src/ui/        渲染层：全部用 DOM 节点构建，不用 innerHTML
src/main.js    编排层：把上面几层串起来
assets/        素材：bg/ 对话背景（表情走图床，刻意不进仓库）
tools/         零依赖打包器 + 词库生成 + 表情本地化 + 抽查脚本
```

几个刻意的设计：

- **系统提示词字节稳定**，只有历史在追加——这是前缀缓存能命中的前提（实测命中 83–91%）。
  动态状态（休息期剩余轮数等）只走界面，不进提示词。
- **上下文超预算才裁剪**，一次裁到 70%，两次裁剪之间窗口不动，同样是为了保住缓存前缀。
- **图片绝不进消息、绝不进 localStorage**，消息里只存「键」。背景走本地文件，表情走远程直链。
- **零依赖**：没有 bundler、没有运行时库，`tools/build-single-html.mjs` 是自己写的打包器。

## 改提示词

界面里没有提示词编辑框，提示词是源码里的常量：

| 想改什么 | 改哪里 |
|---|---|
| 人设、四类标记格式、题目机制、自攻击清单 | `src/content/chat.js` |
| 禁词表、文风规范、认知边界 | `src/content/style.js`（两个模式共用） |
| 出题与判定（拼单词模式） | `src/content/prompts.js` |
| 表情标签与别名（提示词里的可用列表由它生成） | `src/content/emotions.js` |
| 题库 | `src/content/cet4-questions.js` |

改完源码：多文件版刷新即可；单文件版要重跑 `npm run build:single`。

## 素材与生成脚本

背景图在仓库里（`assets/bg/`），打包时内联进单文件；**表情图在仓库外**，走远程图床直链。

```bash
node tools/build-cet4.mjs     # 从 tools/raw/ 的词表生成 src/content/cet4.js
```

表情的地址登记在 `src/content/emotions.js`（每条记两家图床）。想加一张就加一条，
清单、提示词里的可用列表、界面都会自动跟进。

## 使用前请知悉

**模型与费用**：需要自备 OpenAI 兼容端点与 Key。Key 只存在你自己的浏览器里。
对话模式每轮都会把完整历史发给模型，长会话下总消耗是平方级增长——默认开启了上下文限额。

**素材来源**：

- 对话背景与 11 张表情为**本作参考鲸鱼娘形象使用gpt绘制素材**（背景随仓库分发，表情托管在自有图床）。
- `src/content/cet4.js` 由 `tools/build-cet4.mjs` 从 `tools/raw/` 的两份词表生成。
  那两份词表是对公开数据（四级考试大纲词表、COCA 词频表）的筛选整合，
  **再分发前请自行确认上游的权利状态**。
- 题库 `src/content/cet4-questions.js` 为本项目原创。

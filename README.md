# 梦鲸词汇 · 每天一点点

英语词汇学习工具：离线练习、间隔复习，以及和梦鲸边聊边学。当前版本 0.6.0，提供网页版、安卓与 Windows 应用工程。

安卓与 Windows 的安装、备份迁移和构建方式见 [应用说明](APP.md)。网页版仍可直接用 Node 启动或导出单文件；原生应用构建需要安装 package-lock.json 中锁定的依赖。

## 使用

```bash
node serve.mjs
```

打开 `http://127.0.0.1:5173/`。默认进入学习中心，客观题不需要模型或 API Key。

也可打开 `dist/dreamwhale-vocab.html`。这是已打包的单文件版本，代码、28 张表情、固定头像、四时段背景与三张导航插画均已内联，共 36 张图片。浏览器仍需允许本地存储。

单文件已通过本地 HTTP 预览验证。内置测试浏览器禁止 `file://` 导航，因此双击文件的运行方式尚未实测。

聊天和情境表达题需要在「设置」中配置模型接口。请求由浏览器直接发送到所填端点；Key 保存在当前浏览器，学习记录备份不包含 Key。接口需允许浏览器跨域访问。

## 模型连接

默认模型为 `deepseek-flash`。已有保存配置保留原模型名；在「设置 → 模型」选择 DeepSeek 预设即可更新。

预设包括 DeepSeek、OpenAI、Claude、Gemini、通义千问、Kimi、豆包、MiniMax、硅基流动、Groq、Grok、Mistral、OpenRouter、Ollama 和 LM Studio。模型名可自行替换，需使用当前账号有权限调用的模型或部署 ID。

服务商与请求格式可分别选择，四种格式均用于聊天、逐字显示、题目评价和连接测试：

| 请求格式 | 地址示例 | 官方协议 |
|---|---|---|
| OpenAI Chat Completions | `https://api.deepseek.com/chat/completions` | [DeepSeek](https://api-docs.deepseek.com/api/create-chat-completion) |
| OpenAI Responses | `https://api.openai.com/v1/responses` | [Responses 流式事件](https://developers.openai.com/api/docs/guides/streaming-responses) |
| Anthropic Messages | `https://api.anthropic.com/v1/messages` | [Messages](https://platform.claude.com/docs/en/api/messages/create) |
| Gemini generateContent | `https://generativelanguage.googleapis.com/v1beta` | [generateContent](https://ai.google.dev/api/generate-content) |

自定义接口支持 base URL 或完整路径，保留 URL 查询参数；Gemini 完整路径可用 `{model}` 代入模型名。地址下方会显示最终请求地址。认证支持自动、Bearer、`api-key`、`x-api-key`、`x-goog-api-key` 和无需认证，Key 均填写在同一密码框中。

不接受温度参数的模型可关闭「自定义表达随机性」。兼容性选项可切换 `max_tokens` / `max_completion_tokens`、关闭流式用量参数或 JSON 格式约束。Responses 使用 `max_output_tokens`，Messages 使用 `max_tokens`，Gemini 使用 `maxOutputTokens`。Responses 每次发送当前会话上下文并设置 `store: false`。

切换到另一服务商域名的预设会清空尚未保存的 Key。配置复制、保存和备份会保留请求格式与认证选择，导出备份仍不包含 Key。协议和浏览器跨域权限是两件事：端点不允许浏览器直连时，需要使用允许跨域的自有网关。自动检查与本地模拟服务不代表各厂商的付费接口已实测。

## 能做什么

- 「今日」设置每日新学与复习目标、九个主题范围；新词和到期复习分开进入，每组最多 10 个词。当天目标按实际可学、可复习的词数显示。
- 「词库」选择四级、六级或混合，支持全部 / 高频，最多浏览 5,636 个词与表达，搜索单词或释义，按未学、已学、到期、薄弱和收藏筛选，查看用法并练习单词。
- 单词、例句、题干、英文选项、答案讲解和错题提供朗读按钮，也可选中英文朗读。学习朗读使用系统声音，在「设置 → 常用」设置英美音、0.50–1.50 倍语速和离线限制。「设置 → 语音服务」专用于梦鲸聊天，可选阿里百炼或 MiniMax，支持中英文段落、整条消息和回复完成后自动朗读；聊天口音和语速独立保存。
- 「专项」按主题、难度选择 11 种训练。「梦鲸」保留角色聊天和聊天题卡。
- 新学与复习中的选择题先回忆，再打开选项验证；每组结束区分独立答对、提示或重试后答对、看过讲解和跳过。可暂存当前组，返回后续练。
- 客观题本地判分，支持大小写、首尾空白、常见标点归一化，以及题目明确列出的可接受变体。
- 情境表达按题目评分标准调用模型；不确定、网络失败、返回格式错误均不会记成答错。
- 选择题每次创建时洗牌，当前题和选项顺序保存为快照；刷新不会重新抽题。
- 提示分两级。提示后答对、答错后的重试、查看答案，与首次独立答对分开记录。
- 认义、拼写回忆、搭配用法、词形、表达和听辨分别记录复习进度；首页按不同单词统计当天完成量。
- 聊天出题时同时出现可操作题卡。题卡作答进入同一套学习记录；聊天中的口头评价不会冒充已保存成绩。
- 收藏、查找、导出与合并导入学习记录；重复导入不会重复计分。
- 错题自动收进「词库 → 错题集」，保留原题、当时答案、讲解、答错次数和巩固进度；首页也有入口。可以搜索、单题重练或成组重练。
- 首次进入由梦鲸表情引导点击今日、词库、错题集、专项和聊天入口。引导支持上一步、跳过、刷新续接，完成或跳过后不再自动弹出；「设置 → 梦鲸使用引导」可重看。
- 四时段背景跟随设备本地时间，设置中可用预览按钮手动选择。另有跟随系统的深浅色、大字和减少动效偏好。
- 对话支持标题与正文搜索、重命名、置顶、归档、回收站和恢复。永久删除与清空仍需明确确认；回收站不会定时清空。
- 消息可复制、导出 Markdown；编辑用户消息、重新生成已有回复会建立新分支，原会话保留。聊天草稿按会话保存，刷新或切换后恢复。
- 保存最多 30 个模型配置，支持新增、复制、移除和会话内切换。逐字显示可选，支持停止、超时与失败重试；未完整收到的回复不会记成成功。
- 陪学方式有温柔陪学、口语教练、考试复盘和自由交流。交流偏好与记忆可直接查看、编辑、清空，随当前会话保存，并作为之后新会话的默认值。
- 「设置 → 数据」导出聊天与学习备份，导入前展示校验结果及数量。学习历史与收藏合并；聊天冲突另存副本；相同备份重复导入不重复添加。模型 Key 不进入备份。

拼词冒险及其专属界面、设置、引擎已移除。旧浏览器若保存了该模式，会回到学习中心。旧聊天和模型配置沿用原存储键；旧游戏数据不再读取，也不会自动擦除。

共 **12,387 道内置题、11 种题型、5,636 个目标词或表达**。同一词的不同语境和练习方式分别计题。

在今日、词库或专项页面选择「四级 / 六级 / 混合」及「全部 / 高频」，立即保存并同时用于聊天出题。切换保留学习记录、收藏和暂存组，下组使用新选择；旧存档默认全部。

本版新增 8,252 道四级基础题和 213 道六级重点题。后者含 64 个交叉命中词的 128 道语境填空、64 道选择，以及搭配、短语、词形、易混、改错、阅读、表达各三题。所有题目为项目自编；客观题本地判分，情境表达沿用用户配置的模型。词义和听写覆盖主词，语境与专项覆盖其中一部分。

## 场景插画

首页与聊天页使用同一时段的海边书房：清晨 05:00–09:00、白昼 09:00–17:00、黄昏 17:00–20:00、月夜 20:00–05:00。以设备本地时区为准，每 30 秒检查一次，窗口重新获得焦点或从后台恢复时立即检查。手动选择后保持所选背景，切回「跟随设备时间」恢复自动模式。背景与深浅色分开设置。

清晨、黄昏在原白昼书房的构图上生成差分。词库、专项训练与错题集分别使用书本、罗盘与笔记本插画。七张场景图片通过内置 image_gen 按本项目需求生成，原始 PNG 保存在 `assets/scenes/originals/`，网页使用压缩后的 WebP。完整提示词保存在 `assets/scenes/prompts.json`，文件大小和校验值登记在 `src/content/scenes.js`。单文件构建会内嵌全部七张 WebP，无需联网加载。

## 复习规则

每个词义的每项能力分别安排复习。首次独立答对后，下一次间隔为 1 天；之后在到期复习中继续独立答对，依次延长到 3、7、14、30 天。短时间重复答对不推进这个阶段。答错或看过答案后 10 分钟再练；借助提示答对后 1 天再练。

到期复习优先选择最早到期的能力项；每组不重复同一个目标词。组内题目和选项顺序固定，暂停不重新抽题，提前结束不会给尚未展示的词记成绩。筛选没有匹配题时会明确提示。当天新学与复习按设备的本地日期计算，同一词在同一项当天进度中只计一次。

这是一套透明的规则式复习安排，尚未根据真实学习数据校准。

错题集只收录明确答错的题；跳过、查看讲解和模型无法确定不会单独创建错题。以题目 ID 与版本整理，新答错记录会保存原题快照；旧记录从当前题库查找相同版本，找不到时保留作答记录并提示原题暂不可用。

错题连续两次在不同作答中独立答对、且两次至少间隔 24 小时，自动移到「已巩固」。重复刷同一题不会跳过间隔；提示、重试后答对或查看讲解会重新累计，再次答错会回到「待巩固」。已巩固记录保留，可随学习记录一起导出与合并导入。

新增题目时提供稳定 `id`、递增 `version`、`type`、`topic`、`difficulty`、`stem`、`answer`、`accepts`、`targetWords`、`senseId`、`skill`、`variantGroup`、`explanation` 和来源。开放题还需 `grading: 'semantic'` 与 `rubric`。同一语境的题型变体使用同一个 `variantGroup`；不同词义使用不同 `senseId`。当前已对 available 的“有空”和“可获得”用法作区分，其他词义仍需随扩题逐项细化。

旧词表 `src/content/cet4.js` 保留作内容维护资料，运行页面和单文件构建不加载它。其原始筛选含词长限制，不能当作完整四级词表。`tools/build-cet4.mjs` 需自行准备原始资料；新题库不依赖该生成步骤。

学习状态使用独立版本化存储。保存前检查快照冲突；配额不足或坏记录不会静默覆盖为初始状态。旧学习记录自动补齐计划字段，旧的当前题接成一词练习组。题目、选项顺序和组内进度均保存，点击暂存、切换入口或打开设置时也保存当前答案草稿。「学习记录导出」只含学习记录、收藏、计划和偏好，不含正在作答的题、练习组、聊天或模型配置。导入合并历史与收藏，并保留本地计划、练习组和筛选。多标签页使用乐观冲突检查，不提供数据库级并发事务。

「完整备份」另含全部对话（包括归档和回收站）、模型连接配置、陪学默认值、外观偏好与称呼档案；不含 Key、未发送聊天草稿、进行中的练习组和引导进度。可选恢复设置，未勾选时只合并聊天与学习历史。导入限制为 24 MB、1,000 段对话、每段 20,000 条消息及 30 个模型。模型按端点和名称匹配，冲突编号会重新分配，不把远端配置误绑到本地同编号模型的 Key。未找到对应模型时使用本地默认配置，发送前可在聊天顶部选择。

导入先完成格式检查与合并，再暂存聊天正文，最后提交索引；失败时清理暂存记录并尝试恢复同批设置。并发修改会拒绝导入，回滚受阻会明确提示。浏览器崩溃或断电不能保证跨多个 localStorage 键完全原子提交，因此保留原始备份，且不替代数据库事务。

旧会话 v3 的正文、小总结、完整回合裁剪、失败重试和未知用量处理继续保留。单文件和本地服务器可能属于不同存储来源，可通过完整备份迁移聊天与学习记录。
